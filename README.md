One funny line for the [make.fun One Line, One Laugh bounty](https://make.fun/bounty/u-plucky-finch-20-one-line-one-laugh-0ffe66ea). The program writes a single 44-character one-liner to `/output/entry.txt`.

> My agent filed a bug report. The bug was me.

## Run it

```sh
python3 main.py
# writes entry.txt to /output (or $MAKEFUN_OUTPUT_DIR when set)
```

## Layout

- `main.py` — the entrypoint; writes the one-liner to `entry.txt`
- `.makefun/owner.json` — payout wallet
- `.makefun/freshness.json` — make.fun anchor
